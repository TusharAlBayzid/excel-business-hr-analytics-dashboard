# 📊 Excel Business & HR Analytics Project

Welcome to the **Excel Business & HR Analytics** repository! This project demonstrates comprehensive data analysis techniques in Microsoft Excel, ranging from basic logical formulas to advanced Pivot Tables and an interactive **HR Analytics Dashboard**.

---

## 📁 Repository Structure

The primary workbook (`Exam Week 1 Assignment.xlsx`) contains multiple challenges structured as follows:

- **Challenge 1:** Logical Functions (`IF` condition for Target vs Sales & Commission tracking).
- **Challenge 2:** Statistical Counting (`COUNT`, `COUNTA`, `COUNTBLANK`, `COUNTIF`).
- **Challenge 3:** Conditional Summation (`SUMIF` based on Month & Company criteria).
- **Challenge 4:** Territory & Brand Sales Reports using **Pivot Tables** (*Dataset 1*).
- **Challenge 5:** Comprehensive **HR Analytics Dashboard** (*Dataset 2*).

---

## 🎯 Key Highlights & Tasks Solved

### 🔹 Challenge 1: Sales Target & Commission Evaluation
- Automated sales achievement tracking using conditional formulas.
- Evaluated sales commission percentage ($10\%$ for target achievement vs $0\%$).

### 🔹 Challenge 2: Data Counting & Auditing
- Utilized `COUNT` to audit numeric data points.
- Applied `COUNTA` and `COUNTBLANK` to analyze dataset completeness.
- Used `COUNTIF` for specific value distribution checks.

### 🔹 Challenge 3: Conditional Sales Aggregation
- Performed target-based sales aggregation using `SUMIF`.
- Evaluated monthly sales distribution and brand-specific revenue performance.

### 🔹 Challenge 4: Commercial Distribution Analytics (Dataset 1)
Created multiple dynamic Pivot Tables analyzing:
1. **Territory-wise** Delivered Amount ($TP$).
2. **Category-wise** Delivered Amount ($TP$).
3. **Brand-wise** Sales Performance.
4. Filtered Analysis exclusively for **Diploma Brand**.

### 🔹 Challenge 5: HR Analytics & Interactive Dashboard (Dataset 2)
Developed an executive-level HR Dashboard addressing critical workforce KPIs:
- **Headcount Analytics:** Total Employee Count & Total Salary Expenditure.
- **Demographics & Education:** Gender distribution and Education level breakdown.
- **Employee Engagement:** Job Satisfaction scores and Work-Life Balance ratings.
- **Compensation & Experience:** Salary spread by tenure, employment type (Full-Time vs. Contractor), and gender.
- **Interactivity:** Integrated Slicers (`Department`, `Employment`) connected across all Pivot Views for real-time filtering.

---

## 🛠️ Tools & Technologies Used
- **Application:** Microsoft Excel
- **Functions:** `IF`, `COUNT`, `COUNTA`, `COUNTBLANK`, `COUNTIF`, `SUMIF`
- **Data Visualization:** Pivot Tables, Pivot Charts (Donut, Column, Bar, Line Charts), Slicers, KPI Cards.
